- **Task:** Plan 002 follow-up — fix the .bat bugs that surfaced during end-to-end testing
- **Agents:** conductor (self, no subagent delegation needed — bugs were in the .bat files I just wrote)
- **Files:** `uninstall-global.bat` (196 → 209 lines, three bug fixes), `tests/test_global_setup.py` (unchanged — all 30 tests still pass), `.opencode/plans/plan-002-fix-global-setup.md` (verification section restructured)
- **Bugs found during L5 end-to-end retest:**
  1. **`::` comments inside `( ... )` blocks** — `cmd : : was unexpected at this time.` and `cmd : . was unexpected at this time.` errors. Batch parser treats `::` as a label inside a parenthesized block. Fixed 5 occurrences in `uninstall-global.bat` (lines 63, 80-83) and 5 in `global-setup.bat` (lines 194-197, 209) by converting to `REM`.
  2. **`%REMOVE_ARGS%` parse-time expansion returning empty** — `REMOVE_ARGS` was set inside the same parens block where it was referenced, so `%REMOVE_ARGS%` expanded to `[]` (parse-time) instead of the runtime value. Fixed by changing `%VAR%` → `!VAR!` (delayed expansion) for `REMOVE_ARGS`, `GLOBAL_CONFIG`, `MANIFEST`, `PY`, `MERGE_HELPER` inside the parens block. Also changed the `set "REMOVE_ARGS=..."` to use `!` for the same reason. The install script was NOT affected (its `MERGE_ARGS` is set at top-level before any parens block).
  3. **Junction safety check via `findstr /C:` was unreliable** — the findstr substring match against fsutil output inside a parens block with `2^>nul` redirection triggered a Windows batch parser edge case (the `^` escape was being consumed differently in `cmd /c` context vs. interactive). Simplified: dropped the findstr-based check entirely; now the safety check is just "skip if no manifest and no `--force`". The user has already opted into the global uninstall, so removing the junction if the manifest verifies it's ours is sufficient.
- **Verification:**
  - All 30 `tests/test_global_setup.py` tests pass
  - Full install+uninstall cycle via .bat: 13 agents + 2 skills.paths + 1 instruction merged on install; all surgically removed on uninstall; manifest deleted; both junctions removed; scalars preserved
